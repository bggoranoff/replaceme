# Actor Agent

The **Actor Agent** is an autonomous learning agent that plays the game levels generated by the Builder, explores action combinations, resolves stochastic edge cases (e.g. stockouts, temperature swings), and extracts reusable, verified skills.

## Overview

- **Triggered By**: The user clicking the **"Train agent"** button in the UI (or invoked via CLI).
- **Core Function**:
  - Runs fast headless simulation rollouts (50–100+ episodes per level in milliseconds).
  - Tests procedures against hidden stochastic entropy (ambient temperature, equipment quirks, customer impatience).
  - Evaluates win rates and extracts robust recovery policies.
- **Output**:
  - Exports standard `SKILL.md` packs into `skills/<level-id>/SKILL.md` with procedure steps, success checks, game action mappings, and training evidence.
  - Returns `Skill[]` array to the UI to populate the interactive skill cards.
  - Powers the per-skill Q&A chat with users (grounded in the learned `SKILL.md`).

## Usage

```bash
# Run the Actor Agent on a research brief:
python3 -m actor.agent --brief research.json --episodes 50
```
